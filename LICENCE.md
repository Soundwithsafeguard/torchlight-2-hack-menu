## 🧩 About

**Torchlight 2 Companion** is a curated list of Torchlight 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot radar viewer, minimap notes
- **Quality-of-Life Helpers** — inventory catalog, stat tracker, overlay notes
- **Research Notes** — build layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Loot Radar — highlight nearby drops for study routes
- Show Stats — visualize character stats in a compact panel
- Route Notes — record and review dungeon runs
- Playback Speed — adjust overlay refresh for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse gear, gems, and affix notes
- Custom UI Notes — organize player layouts
- Range Indicators — improved skill range visibility

### Aimbot
- Build Notes — segment study on any class layout
- Pet Control Notes — manage pet behavior in the editor
- Skill Cooldown Notes — chain complex rotations in the editor
